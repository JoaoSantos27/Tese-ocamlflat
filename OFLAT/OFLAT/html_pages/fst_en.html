Finite-State Transducers

A finite-state transducer (FST) extends a finite automaton by producing output symbols while it reads input symbols. It defines a relation (or function, in the deterministic case) from input words over an alphabet to output words over another alphabet.

As with automata, transducers have states and labeled transitions. In an FST, each transition carries an input:output label. A run consumes the input and accumulates the output along the chosen path.

In a Mealy machine, outputs are produced on transitions. In a Moore machine, outputs are associated with states. Both are special cases of general FSTs.

A word is accepted if the input is fully consumed and the final state is accepting. The produced output is the concatenation of the outputs along the path.

More information in the course documentation.

Commands

Clean

Removes useless states from the transducer (inaccessible and/or non-productive states).

Determinize

Attempts to determinize a transducer when possible. Some transducers cannot be determinized if they contain output conflicts.

Minimize

Minimizes a deterministic transducer using the algorithm taught in class.

If the transducer is not deterministic, you must determinize it first (when possible).

Productive states

Paints productive states in orange.

A state is productive if it contributes to producing some accepted output.

Accessible states

Paints accessible states in yellow.

A state is accessible if it is reachable from the initial state by some path.

Useful states

Paints useful states in lilac.

A state is useful if it is both productive and accessible.

Clean colors

Clears state colors set by the previous commands.

Show table

Shows the transducer in tabular form.
