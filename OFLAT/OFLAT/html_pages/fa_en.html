Finite automata

A finite automaton is a computation model that can be used to specify a language. A language is a set of words over an alphabet.

The expressive power of finite automata is relatively weak: they describe only languages with a very regular structure, namely Chomsky Type-3 languages, also known as regular languages.

A language is specified by recognition. To test whether a word belongs to the language, the automaton is applied to the word and decides whether it is accepted or rejected.

An automaton consists of states and labeled transitions between states, without memory. One state is initial, and some states are final. To recognize a word, we start at the initial state and consume the symbols of the word sequentially while following available labeled transitions. The word is accepted iff the whole word has been consumed and the current state is final.

Commands

Clean

Removes all useless states from the automaton, that is, all unnecessary and non-productive states.

Make deterministic

Makes an automaton deterministic using the algorithm taught in class.

Minimize automaton

Minimizes a deterministic automaton using the algorithm taught in class.

If the automaton is not deterministic, it must first be converted to a deterministic automaton using the appropriate command.

Productive states

Paints productive states in orange.

A state is productive if it contributes in some way to recognizing at least one word.

Accessible states

Paints all accessible states in yellow.

A state is accessible if it can be reached from the initial state by some path in the graph.

Useful states

Paints all useful states in lilac.

A state is useful if it is both productive and accessible.

Clean colors

Clears the state colors set by the previous command.

Show table

Shows the automaton in table form.
